重点审阅：

- `apps/api/src/silicon/finance/service.py`：原调整关联、状态/版本、负额限制、防重复、更正金额投影和原 occupied 保护。
- `apps/api/src/silicon/finance/routes.py`：finance.correct、重放前来源检查，计划和原调整共同参与命令作用域。
- `apps/api/migrations/versions/0014_finance_corrections.py`：同租户/同计划复合外键、原调整唯一更正、负额触发器、FORCE RLS、不可变历史及非空更正降级拒绝。
- `apps/api/src/silicon/finance/models.py`：更正输入及旧幂等响应缺少 corrections 时的兼容默认值。
- `apps/web/src/Finance.tsx`：原调整旁的更正入口、必填原因和依据、历史关联展示及已更正后隐藏重复入口。
