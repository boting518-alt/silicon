## R1 / P1：合同清理工具会误删有效采购附件和期初原始 CSV

定位：

- apps/api/src/silicon/inventory/routes.py：storage、upload_attachment、import_file。
- apps/api/src/silicon/inventory/service.py：preview_import。
- infra/clean_contract_files.py：clean 中 contract_files 引用查询及随后 unlink。

新增采购文件与期初 CSV 使用同一 SILICON_FILE_ROOT/<tenant UUID>/<storage UUID> 目录。有效引用分别保存在 inv_attachments、inv_imports；但既有 clean_contract_files.py 只查询 contract_files，将不在其中且超过 24 小时的 UUID 文件视为孤儿。

真实触发步骤：

1. 上传采购合同/收货附件，或预览/提交期初 CSV。
2. 文件仍被 inv_attachments 或 inv_imports 有效引用，等待超过 24 小时。
3. 在同一租户执行既有清理命令 --apply。
4. 清理工具不识别新增引用，删除原文件；数据库关联和冻结快照仍在。
5. 随后采购附件/期初原件下载失败；尚未提交的期初预览也无法读取原 CSV 完成提交。

影响：常规维护操作会造成有效业务原件丢失，包含冻结采购合同的来源材料。默认 dry-run 不足以消除问题，因为正式 apply 是已提供且允许执行的维护流程。此问题不要求任何越权或恶意输入。

独立复现：在临时目录创建超过 24 小时的实际 UUID 文件，执行真实 clean(apply=True)，数据库及授权边界用替身提供“无合同附件引用”的状态；结果删除 1 个文件。检查查询确认完全没有访问 inv_attachments/inv_imports。真实文件删除已复现；未冒称真实 PG/API 全链路复现。

修复要求：

- 文件回收统一识别所有共享存储引用，或采用正确隔离的存储命名空间。两种方案均需兼容现存记录，不能仅对新上传生效。
- 保留有效合同附件、采购合同/收货附件、预览和已提交导入原件；冻结引用不可被当作孤儿。
- 只有确认无业务引用且满足保留期/在途保护的对象才允许删除。
- 重新检查共享引用、提交可见性和锁顺序；不能因增加库存锁而与既有合同/目录锁形成反向锁。
- 清理缺失表或查询失败时应保守失败，不能退化为全目录删除。

必要真实 PG/文件回归：同租户同时准备合同附件、采购附件、收货附件、预览 CSV、已提交 CSV、无引用孤儿及可回收已删除合同文件，调整文件年龄后执行 dry-run/apply，证明只删除应回收项。下载及 hash、期初提交、冻结快照保持。另测跨租户、在途写入/提交与清理竞争。

修复前，不应将当前清理工具用于包含 TASK-008 文件的目录。这是针对已复现误删的具体限制。

## R2 / P2：采购附件在鉴权及大小检查前无界读取请求体

定位：apps/api/src/silicon/inventory/routes.py 第 165–174 行，upload_attachment。

该入口首先执行 data = await request.body()，之后才进入 tx 检查会话、租户、对象和权限，再调用 Store.put 检查文件大小。路由声明的 context 依赖本身不执行鉴权；现有请求 ID 中间件也没有请求体限额。

结果：配置的 10 MiB 等上限仅限制最终保存，不能限制请求体被整体读入内存。超大或未授权请求仍先消耗完整请求体的内存与读取时间，影响其他业务请求。相比已实现的 TASK-007 先授权、再流式计数读取，这是新增入口的退化。

独立探针执行真实路由 endpoint，用替身请求体和明确拒绝的授权边界记录顺序，确认“完整 body 读取 → 授权拒绝”；测试请求体超过配置限额。没有使用大规模流量或进行资源耗尽测试。

修复要求：

- 先完成当前会话、预期租户、对象及操作权限校验，再消费文件流；避免在上传期间持有业务事务锁。
- 流式累加实际字节，超过配置上限立即停止并返回 413；不能只信 Content-Length。
- 正式写入时重新核实权限、对象状态、expected_version 和幂等条件；延续格式解码及失败文件回收保护。
- 与 R1 一起覆盖共享文件写入/回收边界，不为绕过验证另设无保护存储入口。

必要回归：无 Content-Length 的分块超限上传、中途超限停止读取、未授权请求不消费完整文件、上传期间撤权/对象冻结、同键重试、合法限额内文件上传下载。记录拒绝后无可见附件或错误库存事实。
