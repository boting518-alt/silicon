## R1 关闭依据

原实现保留了撤销后的设备和实物记录，但重新完工仍拒绝历史 SN；直接放开 SN 校验也会碰到设备与实物唯一约束。修复已将稳定设备身份与每次完工记录分开处理。

1. **保留设备身份。** 更正完工沿用原设备 ID 和库存实物 ID，追加新的完工记录、成本层和库存移动，未通过删除历史记录或创建第二台同 SN 设备规避约束。
2. **显式、受限的更正入口。** `correction_of` 必须引用同工单、同设备的最近一次已撤销完工；服务校验有效撤销关系，并拒绝仍存在库存、有效预留、下游移动或有效安装关系的来源。普通历史 SN 重用仍被拒绝。
3. **历史和当前状态分离。** `asm_completions` 保存每次完工及撤销关系，安装历史关联具体完工。设备列表投影最新完工信息，对账按有效完工统计，撤销后的有效成本不重复计入。
4. **数据库约束补强。** 新迁移包含同租户关联约束、每设备和每工单最多一次有效完工的唯一索引，以及完工记录不可随意改写的约束。更正来源必须属于同一设备且已撤销。
5. **兼容既有记录与重放。** 迁移回填旧设备的完工历史及安装关联；未提供更正意图时保持旧成功命令的哈希兼容，显式更正意图参与幂等判断。存在更正历史时拒绝有损降级。
