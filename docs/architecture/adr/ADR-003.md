# ADR-003：台账与快照

状态：proposed（TASK-000 执行默认，等待独立复核）
日期：2026-09-09

## 背景

金额、库存、已签合同不能依赖可变页面数组，历史应可追溯。

## 决策

Decimal/NUMERIC、不可变报价/合同版本、库存移动台账、逆向冲销、幂等与 expected_version 同事务校验。SN 个别计价，批次 FIFO；零件/WIP/成品成本连续。

## 替代方案

拒绝原位覆盖已过账记录、前端权威计价与凭余额直接改库存。

## 影响与验证

租户复合键与 RLS 为基础；报价发布审批绑定内容 hash，变化失效；收款、发票、验收、物流独立。
