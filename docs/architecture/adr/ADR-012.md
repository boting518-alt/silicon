# ADR-012：合同工作资料、线下签约登记与私有附件

状态：TASK-007 review_ready；开发实现决策，非业务验收。

## 冻结与状态

保留 0007 contract_drafts 的不可变来源。contract_workspaces 一对一扩展同一合同 id，可编辑主体/非金额条款；contract_payments 保存 NUMERIC(18,2) 正金额及有序节点。来源商业内容不接受客户端覆盖。资料版本与附件关联变化使签约确认 hash 失效。

签约全部由 admin 人工确认线下事实，绑定 expected_version/hash/key；生成唯一 signed_contracts 及唯一 sales_orders，同事务审计。源报价当前过期/撤回阻断新登记，历史日期不豁免。签约副本、订单、来源附件清单受权限及不可变触发器保护；没有签约变更/解除。订单 pending_fulfillment，不占库存、不生成应收收款、发票或交付记录。

签约后付款约定不更改。固定日期直接保留；signing 从登记的线下日期加非负日历天；delivery/acceptance 未接入，resolved_due_date=null，awaiting_trigger。无百分比辅助/换算。节点必须正金额，零金额合同当前缺明确业务政策，阻断 ZERO_CONTRACT_POLICY_UNCONFIGURED，不修改报价合法零价规则。签约日期不能晚于服务器业务日期；开发环境沿服务器本地日期，正式时区配置未接受，不代表生产就绪。

## 身份、字段与锁

沿用当前会话/上下文/CSRF → 稳定排序参与者身份共享 → catalog共享 → quote共享读/排他写 → CRM共享；合同所有命令复用 quote 租户锁，因此不再追加反向锁。报价撤回/修订、签约、资料编辑和附件关联删除排序一致。文件校验为有界本地读取，没有网络发送；上传流在业务事务外，写入关联时再次授权/校验版本。

contract.write/download/contact 对 member/admin；contract.sign 对 admin；viewer read/download；所有入口当前客户可见性仍重查。联系方式字段在本模块对无 contract.contact 者清空，主体姓名不是内部身份。内部销售/售后保存 membership 引用及服务器姓名快照，新分配检查当前资格；保留旧分配姓名、每次资料保存追加不可变版本历史。草稿里保留停用人员历史但新签约要求当前有效。

幂等唯一域 tenant/actor/operation+contract或attachment/id/key；重放先重新授权，再读取结果。签约不同key同version/hash返回同一版本；内容不同不能借重放更改。附件事件不自动标记 signed。

## 文件与故障

受控本地适配器根由 SILICON_FILE_ROOT 配置，按 tenant UUID / 随机 storage UUID 存储，无公开静态目录、无用户路径。默认10 MiB，允许配置1 KiB至20 MiB；流式计数拒绝超限。仅PDF/JPEG/PNG，扩展名与内容结构/签名检查，检测到的类型、实际大小、hash由服务端生成。不是AV扫描，不承诺文件无恶意软件；主动HTML/SVG不接受，下载强制attachment/nosniff。

上传后metadata pending，无下载权限；attach后linked并递增资料版本。签约仅冻结linked文件并再次核对实际字节/hash。已冻结附件不删除、不替换；删除草稿附件标deleted，下载立即拒绝，物理回收与事务解耦。签约后上传创建 supplemental=true 的新记录，可单独关联与下载，标明不属于原签约冻结集；不能替换旧附件或更改原快照。其权限与对象隔离相同，既有签约workspace版本不因补充材料重写。

文件与PG不具备跨资源原子提交。失败或提交结果不明时保留不可见孤儿，避免误删已提交文件；成功重放产生的多余新文件删除。infra/clean_contract_files.py 默认dry-run，需当前授权admin及明确tenant；在quote排他锁内重查元数据，仅清理超过24小时且无pending/linked引用的文件。上传持有文件锁，清理非阻塞跳过在途文件；不扫描其他企业目录，不删除未知命名或符号链接。pending遗留由授权用户显式删除后进入清理，不能靠TTL误删正在处理的合同。

正式发布保护仍保留。真实文件服务生产加固、AV、生产证书与存储运维未验收，本任务只能开发环境验证。
