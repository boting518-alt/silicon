# ADR-005：TASK-001 骨架与可复现运行

状态：TASK-001 实施决策，review_ready 后待独立复核。日期：2026-09-09。

## 决策与原因

沿用 ADR-001～004，不变更 Vite/FastAPI/PostgreSQL/独立 Worker 架构。npm 与 uv 分别管理 JS 和 Python，直接依赖精确版本，传递依赖锁定在 package-lock.json / uv.lock；版本依据见 dependencies.md。不引入当前空壳不需要的路由、表单、图表、对象存储或模型 SDK。

本地统一 PostgreSQL 17.11；用户在执行中明确要求升级本机 14 到 17，已通过 Homebrew 升级并以复制式 pg_upgrade 迁移，保留旧库和备份。验收用本机 17.11 程序创建独立临时集群，不借用常驻数据库。CI 可用官方源码 hash 固定构建相同版本；Compose 提供可选开发 DB，当前 Docker 未运行，不能声称容器启动已验证。

## 迁移与运行角色

0000_baseline 是无业务表的空起点；0001_platform 只建 jobs/outbox_events 与约束、索引。silicon_migrator 负责对象所有权与迁移；silicon_app 只有所需 DML 和版本读取权，非超级用户、非 owner、无 BYPASSRLS，不能创建表。没有实现 TASK-002 的会话、membership、RLS 或租户数据模型。

外置卷实际产生 ._*.py，Alembic 原始扫描会发生 null bytes 异常。因此 infra/migrate.py 从原迁移目录复制到临时目录并排除 AppleDouble/字节码后调用 Alembic；原目录及参考 Demo 均不删除或改写。新增迁移仍写回 apps/api/migrations/versions；运行只支持显式 upgrade/downgrade/current/heads/history，不把新 revision 生成到临时目录。

## Worker 边界

当前仅命令行可入队固定 smoke 类型，无任意 payload、业务数据或外部调用；SILICON_ENV 只接受 development/test，生产启动显式拒绝。平台 smoke 的 dedupe_key 仅为本开发测试队列的唯一域；不能照搬为租户命令幂等键。

领取使用事务行锁与 SKIP LOCKED；租约 token 隔离旧 Worker，过期重领、心跳、尝试上限、指数退避及 failed 状态均持久化并测试。当前 smoke 为有界的即时 handler，在处理前刷新租约；将来长任务须加持续心跳及副作用幂等，未实现前不得注册。outbox 仅有表，不发送任何事件/通知，也没有对外投递器。

## API 和 UI

health 不查数据库；ready 查询实际迁移版本，连接失败或版本缺失返回 503，响应只有 code/message/request_id，无 SQL 或 DSN。API/Worker 不持有迁移凭据（即使开发 .env 同时列出，应用代码仅读取 DATABASE_URL；部署须分进程注入）。当前没有业务写 API。

UI 只复用硅屿 token 的最小壳和真实连接检查，保留浅背景、细边框、深绿与留白；完整侧栏/业务页及视觉对照仍属 TASK-003。OpenAPI JSON 与 TypeScript 类型由命令生成，API 失败显示错误，不回退假数据。

## 验证限制

本机锁定依赖下 build/typecheck 和真实 PostgreSQL/API/Worker 测试通过；远程 CI 未运行，Docker 启动、OIDC、视觉截图/业务 E2E 未运行。仅交付工程骨架，不代表生产就绪。
