# ADR-001：模块化单体

状态：proposed（TASK-000 执行默认，等待独立复核）
日期：2026-09-09

## 背景

原 Demo 为原生静态页面，本地尚无目标框架；首客户规模不需要微服务。

## 决策

采用 React/TypeScript/Vite + FastAPI 模块化单体、PostgreSQL、同包独立 Worker、私有 S3 对象存储。模块通过应用服务协调同库事务；jobs/outbox 至少一次投递，副作用幂等。

## 替代方案

不选微服务/默认 Redis/Temporal；未来确有复杂长流程再评估。既有 Next.js 仓库时保留其框架，但本次无此约束。

## 影响与验证

生产需 Python 容器；不得套用 Sites D1 或 Worker 托管作为生产数据库/后端。版本组合由 TASK-001 锁定。
