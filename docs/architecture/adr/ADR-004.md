# ADR-004：受控 Agent

状态：proposed（TASK-000 执行默认，等待独立复核）
日期：2026-09-09

## 背景

模型不具备确定性计价与授权能力，上传内容可能含提示注入。

## 决策

模型仅生成结构化候选；Worker 经权限、预算、schema 和领域规则调用白名单工具。审批绑定 proposal/版本/hash，执行再校验。

## 替代方案

不开放 SQL、任意 Shell、直接改库或真实付款工具，不自建多机器人平台。

## 影响与验证

外发、正式报价、合同变更、出库、核销必须有人类业务角色确认；只读摘要/草稿可自动。完整记录来源、成本、超时与 uncertain；常规业务不依赖模型可用性。
