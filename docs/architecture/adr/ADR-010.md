# ADR-010：配置报价草稿与后端权威试算

状态：TASK-005 实现决策，等待独立审查。无既存完整任务书，以下开发规则不冒充真实供应商/商务政策。

## 数据与授权

0006_quotes 增加 quote_drafts、quote_selections、quote_exclusions、quote_discounts、quote_commands。草稿不是正式报价；父表记录客户/项目/已发布 BOM/数量/口径/折扣身份/version，追加/排除行有类型关系表；服务端计算结果 JSON 为 Calculation 有类型快照。所有表 FORCE RLS/tenant_visible，跨企业复合 FK。原始折扣码不保存，只存 tenant+规范码 SHA-256；该散列不是高熵秘密保护方案，因此运行角色不向普通目录暴露政策表和 code_hash，访问必须经服务端权限。测试码仅虚构值。

quote.read 对 admin/member/viewer；quote.write 对 admin/member；quote.discount 对 admin。每次同时检查当前客户访问权（crm.read 与 owner/data_scope）、项目属于客户。使用他人不可见客户不能借草稿绕过；换客户时旧/新客户都检查。读取已有折扣草稿可以查看当时金额，修改/试算带折扣需 quote.discount；非折扣维护角色可以移除优惠再保存。没有生产认证替身。

锁顺序：会话/membership → catalog 共享锁 → quote 企业共享读/排他写锁 → CRM 父记录共享锁。目录写者只取 catalog 锁，不进入 quote/CRM；CRM 写者不取 catalog/quote，报价锁后不再获取其他 membership 锁。所有金额/图/价格查询在该事务内完成，协调目录写及多表读取。草稿修改串行并校验 expected_version；幂等键按 tenant/actor/operation 分隔，重放前重查客户及优惠权限。试算/折扣解析只读业务数据，但使用 POST、CSRF 和 quote.write 验证，不是核销。

项目 FK 延迟至提交：既有 CRM 编辑会在同一事务删除并重建项目行，相同项目 id 可正常保存；删除仍被草稿引用的项目则整笔回滚。没有级联删除草稿。所有新增运行权限最小化；discount 配置仅操作员迁移角色显式执行，并按相同锁序维护；没有公开修改政策 API。

## 配置与商业行

只选固定已发布 package/BOM。根主体商业数量 1；技术展开中的 included 部件免费展示，不生成商业行；separate 和追加行按 SKU 汇总数量计价。排除技术行仅改变技术配置，不从根基价减钱。替换方式为显式排除原 SKU + 添加新付费 SKU；添加仍保留的同 SKU 被拒绝。展平嵌套行可分别选择，排除包件主体不隐式隐藏内部件，界面逐行显示；没有库存装配或商业退款。

报价时从当前 SKU 读取启停/类别/规格，覆盖嵌套 included 选中部件的当前有效性；发布快照从不改写。开发完整性要求 host/cpu/memory/psu/system_disk，另保留原 BOM 必选行类别；替换同类后可满足类别完整性，但不等于型号兼容。GPU 与扩展可选，若所选 BOM 将其列为必选则不可默默忽略。规则使用原版本来源及当前选中规格，有限 PASS/WARN/BLOCK/UNKNOWN；缺资料始终 UNKNOWN，不把金额可算视为可销售。

## 金额、时效与折扣

首期 CNY、选定 scope 与 tax_included，精确匹配当前已发布价格，不回退其他范围/税口径。税额、运费、汇率未配置，不换算或硬编码 13%。单价 NUMERIC(18,2) → 每类商业行单价×数量 HALF_UP 到分 → 加总单位小计 → 乘整机数量 HALF_UP 到分 → 全单单码优惠 HALF_UP 到分并受最高优惠/本金约束 → 相减到分。上限 9999999999999999.99，溢出明确拒绝。API 金额统一十进制字符串；不允许客户端 total/discount_amount。价格未知/过期/未来价为 null，不当零价；明确零价为 0.00。

折扣仅支持单个百分比，整数基点 1～10000，不叠加。启用、[from,to)、企业、scope、税口径、最低订单额和最大优惠均检查。无真实配置则拒绝，开发夹具示例 DEMO5 为 500 基点、最高 5000 CNY，不是获批真实政策。没有次数限制、库存式优惠预占或核销表；同时试算/保存均可成功，不消耗权益，不宣称已成交。无条件赠送或自主客户端覆盖优惠金额的入口。

保存会重新权威计价，允许带缺件/缺价/无效优惠的待补全草稿；result.total 不完整时为 null。金额完整仍 sale_ready=false，因为真实销售/发布政策未配置且 TASK-006 未授权。UNKNOWN/BLOCK 展示原因；没有报价发布按钮。

GET 详情返回 saved_calculation 与 current_calculation，两者不同 fingerprint 时 needs_reprice=true。fingerprint 排除纯观察时钟、包含配置和金额/价格来源/当前 SKU/兼容/优惠结果，价格跨有效期或 SKU 变更会提示。前端修改配置立即隐藏旧试算；重新激活窗口也隐藏试算并提示重算。界面显示计价时刻和价格期间，保存始终再核验，试算不是持久锁价承诺。后台实时推送、报价锁价与审批有效性属于后续任务。
