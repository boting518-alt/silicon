# ADR-013 — 采购、库存移动和期初边界

status: review_ready；TASK-008。依据任务书，首期仅CNY、piece整数数量；不实现预留、销售出库、FIFO消耗、应付或付款核销。

## 交易与锁

沿用真实会话行锁与membership授权；请求必须携带预期企业及会话上下文。锁顺序为会话/membership → catalog共享锁 → inventory租户读共享/写排他锁。库存写事务在此边界内完成额度、净到货、位置/状态数量、成本层、投影及审计，读聚合也持共享锁。跨租户可并行；单租户写串行是首期可审查的吞吐取舍，不在此任务引入细粒度锁复杂性。

租户表RLS/FORCE RLS与复合外键防串租户；运行角色silicon_app。命令身份包含tenant/actor/action/source/key，参数摘要冲突拒绝，重放前重新检查当前操作/字段权限及来源可见性。命令日志不是外部发送。正式生产保护保留。

## 采购与冻结

采购合同草稿可修改，生效冻结供应商、我方与商业行；订单只来自已生效合同。草稿订单即占用合同数量，取消未到部分释放额度；合同增量以独立不可变追加记录增加同价数量，不能修改原快照。换价或减价不在首期增量流程。订单确认冻结商业内容；交付进度取未冲销收货减去未到取消，不代表付款。

## 实物、成本与移动

SKU复用catalog，单独追踪配置指定SN或batch；有成本层后锁定。SN标准化仅首尾空白裁剪与Unicode NFC，保留大小写与标点；唯一身份为tenant/manufacturer/SKU/normalSN，保留原值。物理unit与成本层分开：错误入库整张冲销至零后，新更正入库仍使用原unit ID，新成本层不改写旧层。批次外部编号相同也保留独立层，FIFO排序以层created_at/id；本期不消费FIFO。

收货草稿不产生库存；过账待检。质检只从pending到qualified/quarantine，位置不同时变；移库保持状态。转移先扣源后增目标，台账成对、投影同事务；全局数量与携带成本净额零。仅qualified自有计入本期合格数量；明确预留系统未实现，不能称“扣预留后的可承诺量”。

层金额为NUMERIC(18,2)，输入两位小数，不做税费换算；逐件整数乘单位成本无分摊尾差。采购价格、可抵扣税字段和库存成本分别记录，无税率或抵扣资格推断。成本状态unknown/provisional/confirmed；unknown必须NULL、不得0；已知0有效。已知小计与未知数量分开，客户代管不计入自有成本。未确认税费政策保持unconfirmed；有明确人工依据的暂估/确认录入不伪称正式财务政策。

已过账收货、成本事实、移动、命令与附件不可改删；允许的投影/层version更新不改变成本原值。错误更正只整张逆向，新记录关联原记录、原因、操作者、请求。按层检查后续未逆向移动，依赖存在拒绝；先逆序撤销质检/移库再撤销收货。禁止借此实现采购退货/报损。数量和成本历史查询来自台账，当前投影差异单独报告不自动修平。

## 期初与文件

期初显式截止日，导入日期必须等于截止日。预校验只保存原CSV与验证记录，不影响库存；提交重新校验、整批原子写入。规范化字段并按external_id排序做内容hash，同时external_id业务身份唯一，换键/行序不重复。原CSV保留精确字节，由TASK007同一私有Store持久化；CSV用明确有界解析而非冒充PDF。PDF/JPEG/PNG采购附件沿用原解码器与私有下载；元数据关联采购合同或收货，不复用销售合同ID。

导入关闭后才允许截止日之后采购收货；未启用期初而直接首笔收货视为跳过期初，之后禁止普通回填。首笔业务收货前可凭专门权限/原因/审计重开同一截止日；首笔后拒绝，复杂迁移留TASK016。未知SKU/跨租户库位/重复SN/行身份/非法成本/币种等任一行错误整批不入账。

## 权限与证据

admin拥有采购及成本配置/写/生效，member仅库存读取、收货、质检、移库、授权下载，viewer只库存读取。成本字段权限在服务端输出前裁剪，带成本写参数在重放前重查成本权限；不靠UI隐藏。库存角色的企业内数量视图是明确仓库工作范围，不因此获得客户详情或采购金额权限。

使用独立临时PG/IdP；测试登录替身、真实OIDC、组件替身、浏览器操作分别记录。附件类型校验非AV，Store监测的Reviewer环境限制随TASK007历史保留；没有修改证书信任或关闭验证。

当前成本投影由余额投影乘不可变单位成本计算，不另存可漂移的金额字段；对账分别返回台账与投影的已知成本/未知数量，并在差异行定位数量及金额。无成本权限同时移除该比较。不可变移动的命令版本固定为1，逆向仍校验该版本；成功命令重放在业务版本检查前返回原记录。关闭期初后拒绝新预览，已过账同内容语义重放保留。
