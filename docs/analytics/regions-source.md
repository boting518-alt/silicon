# 省级地区数据与示意图 v1

本项目使用确定性省级代码/名称表，含 34 个省级单位、明确海外和地区待完善两个独立分组。数据文件：[regions.py](../../apps/api/src/silicon/analytics/regions.py)。版本：silicon-province-tiles-v1，2026-09-12。

代码层级依据国家统计局《统计用区划代码和城乡划分代码编制规则》（前两位为省级代码）：<https://www.stats.gov.cn/sj/tjbz/gjtjbz/202302/t20230213_1902741.html>。使用行政名称和代码事实，不复制第三方地图、底图或行政边界数据。

方格行列布局由本项目原创，以 CC0-1.0 提供；不含地理坐标，不表示精确边界、面积、距离或客户办公位置。中国省级分组含台湾、香港和澳门；海外必须是明确标记，其他未识别字符串全部归入地区待完善。短省名、完整名称及六位代码进行精确匹配；不从街道、电话或客户名称推断省份。

视觉为省级方格分布示意，手机改为有标签的区域网格。地区贡献表始终同时存在，不依赖外部地图服务。没有外部地理编码请求，也不传送客户地址。数值由后端同一指标 groups 返回；颜色仅表示是否有贡献，不能替代数值说明。
