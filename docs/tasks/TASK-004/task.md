## 数据与功能

- SKU：租户内编号唯一、名称、类别、制造商、销售品牌及自有/第三方属性、启停；制造商和品牌为独立身份，供应商不混入。规格以有限类型列表达主机/CPU/GPU/内存/电源/系统盘/数据盘/网卡/IB 卡：插槽、内存代际/容量、功率、槽宽、接口、容量和速率等，不用任意 JSON 作为唯一模型。
- 包件和 BOM：主体 SKU、草稿、独立版本、部件 SKU/已发布包件版本引用、必选/可选、正整数数量；技术包含行与另计价行分开。包含件不自动收费，不提供无商业依据的替换抵扣。支持已含电源与不含电源两类虚构包件。自引用/循环、跨租户关系和无效数量拒绝。
- 发布不可原位修改；修订另建草稿版本，保留旧版完整快照。规则集版本及来源随发布固定；有限示例检查区分 BLOCK、WARN、UNKNOWN，资料缺失不得显示通过。非通用规则语言，不承诺完整硬件兼容。
- 价格表：草稿/发布/修订、SKU 条目、CNY、含税标志、显式适用范围、UTC 有效期；金额 NUMERIC/Decimal、API 十进制字符串。未配置/过期/零价有区别。同租户同 SKU/范围/含税口径的已发布有效期重叠拒绝；边界为左闭右开。查询给出表、版本、条目、期间和来源。旧版本不可回写。不做税额换算，不硬编码税率，不返回内部成本。
