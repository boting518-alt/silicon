二、业务目标

让企业负责人能够回答：

- 本期签了多少合同，交付了多少设备，实际收到多少钱？
- 哪些客户、地区和产品贡献较高，是否过度集中？
- 哪些应收逾期，哪些付款即将到期？
- 哪些库存积压，设备和资金在哪个环节停留？
- 在供应商处的返修件是否超期？
- 哪些经营问题需要立即进入业务页面处理？

每张卡片、图表、地图和排行都应能追溯到业务明细。
展示口径不明确或数据不足时，明确说明原因。

三、本轮边界

- 自动催款、自动采购、外部消息或资金操作。

可以为测试和演示建立独立、明确标识的虚构夹具，

五、时间与历史口径

1. 明确区分：
   - 期间流量：本期签约、实收、实付、发货、退货等。
   - 截止日存量：库存、未结应收应付、在外返修等。

2. 经营日期沿用既有 Asia/Shanghai 口径；
   API 边界和时区转换集中实现。
   时间范围使用明确的半开区间，避免月底漏数或重数。

3. 默认按截至查询时已知的事实重建历史业务日期，
   在页面标明该口径。
   后补录、冲销和更正应有明确的时间归属规则。

4. 不用今天的余额冒充上月末余额，
   不把当前“已冲销”布尔值直接应用到冲销前的历史日期。

5. 优先利用已有不可变事件、移动和逆向关系重建历史。
   某项缺少可靠历史时间时：
   - 只支持当前值，或明确返回历史数据不足。
   - 不伪造历史状态。
   - 如需补充未来记录字段或日快照，保留兼容迁移，
     并明确快照开始日期，不能虚构之前的数据。

6. 图表和下钻返回统一过滤条件与统计时间。
   多请求可能跨越业务写入时，使用一致读、快照标识
   或明确刷新检测；不能悄悄混合不同版本的总额与明细。

六、经营驾驶舱

首屏分为三个业务区域，沿用当前风格：

A. 经营规模
- 本期签约金额与合同数。
- 本期发出、退回及净交付设备数量。
- 本期实际收款、付款、退款及净现金流。

B. 资金与库存
- 截止日未结应收、未结应付。
- 逾期应收及近期到期应付。
- 自有库存已知成本与未知成本数量。
- 库龄结构、在制及售后领用暂存。

C. 待处理事项
- 逾期应收。
- 长期未交付订单。
- 长库龄库存。
- 待归还客户设备。
- 超预计返回日期的 RMA。
- 需要处理的未知成本或地区资料。

阈值明确标识为当前筛选条件或产品默认值，
不把规则提醒表述为 AI 预测。

事项点击进入原业务详情；
没有对应权限时不暴露明细或提供越权链接。

七、签约、交付与客户分析

1. 签约金额、实收金额、净现金流分别展示，
   不称为营业收入或利润。

2. 支持按现有真实字段分析：
   客户、地区、产品、品牌及业务负责人。
   不存在可靠字段时明确不支持，不从字符串猜测。

3. 销售合同、订单、设备、付款是一对多关系，
   聚合前按各自事实粒度去重。
   不将合同金额按设备数、付款数或发货批次数重复累计。

4. 客户分析至少包括：
   - 有业务客户数。
   - 客户签约金额排行。
   - 客户未结应收排行。
   - 前 N 客户集中度。
   - 按期间首次签约判断的新增成交客户。

   若展示“新增建档客户”，与“新增成交客户”分开。

5. 产品排行按冻结销售事实或明确设备事实统计，
   不因当前目录改名、调价或停用而改写原交易。

6. 退货影响净交付；
   不自动减掉原签约金额。
   商业金额变化必须来自已有受控业务来源。

八、客户与销售地图

1. 首期支持中国省级分布，
   海外和无法识别的地区单列，不能静默丢弃。

2. 地图至少可切换：
   - 客户数。
   - 签约金额。
   - 净交付数量。
   资金地区指标仅在口径可靠且有权限时增加。

3. 明确地区归属：
   - 客户分布：当前客户注册地址或明确地区字段。
   - 签约分布：优先冻结签约地址/地区。
   - 交付分布：优先实际发货收货地区。

   缺少历史地区快照时可以按当前客户地区关联展示，
   但必须在名称或说明中标明；
   不冒称交易发生时的地区。

4. 优先使用标准行政区代码及确定性映射。
   无法可靠归一化的地址进入“地区待完善”，
   不猜测省份，不随机生成坐标。

5. 地区中心点仅用于区域展示，
   不能当作客户真实办公地点。

6. 地图、排行和表格使用同一聚合结果。
   含未知/海外分组后，地区合计与总览可对账。

7. 地图数据来源、版本和使用许可记录在项目中。
   优先使用可随项目交付的静态数据，
   无外部地图服务时页面仍可使用地区表格。

8. 提供颜色图例、数值提示、空状态和移动端布局；
   不只靠颜色传递差异。

九、库存结构、库龄和实物周转

库存必须区分：
- 自有原料/备件。
- 在制。
- 成品。
- 售后领用暂存。
- 客户代管。
- 供应商在外保管。
- 待检、合格、隔离等状态。

客户所有件不得计入公司自有库存成本。
未知成本不是零成本：
展示已知成本合计、未知数量和完整性提示。

库龄：
1. 明确采用的起点，例如原入库时间。
2. 移库不得重置原库龄。
3. 成品完工时间与原材料入库时间是不同口径。
4. 销售退回后，可同时展示：
   原始来源年龄与本次重新在库时长。
5. 无可靠入库日期时归入未知库龄。
6. 分档边界清楚，合计与库存明细一致。

建议首期分档：
0～30、31～60、61～90、91～180、180 天以上，
具体边界按自然日明确实现。

实物周转：
- 可展示已出库设备的“完工至首次发货天数”。
- 可展示采购件“入库至首次实际消耗天数”。
- 明确样本数、排除项和时间范围。
- 只对已完成样本计算的均值，要同时展示尚未完成数量，
  不隐藏长期滞留项造成选择偏差。

十、资金周转与账龄

1. 应收/应付账龄按未结项目、到期日及截止日重建，
   不按合同签订时间替代到期日。

2. 质保金未释放时单列，
   无到期日期不得计为逾期。

3. 预收、预付、普通待分配金额分别展示，
   不把它们与应收应付随意相减后称为余额。

4. 退款、核销撤销、金额调整与误减更正
   使用 TASK-011 的有效事实规则。

5. 至少提供：
   - 未到期。
   - 逾期 1～30、31～60、61～90、90 天以上。
   - 待释放/到期日未知。
   - 明细合计与资金子台账一致。

6. 可以展示有明确关联的业务耗时：
   实际资金日期与对应结算节点之间的天数等。
   必须标明是经营样本指标，不混称标准财务周转率。

7. 不得以“实收 / 当前应收”冒充应收账款周转率，
   不得以“实收 / 采购付款”冒充资金周转率。

8. 标准库存周转、应收周转、应付周转及现金转换周期，
   只有在分子、平均余额、历史覆盖和期间口径完整时才计算。

   若用期初期末均值，明确标明；
   若用日均余额，需有完整日序列。
   不使用单个当前余额冒充期间平均。

9. 现有经营子台账缺少可靠收入、销售成本或完整平均余额时，
   指标返回“暂不可计算”，列出具体缺失项。
   不输出 0、Infinity 或伪造的正常数值。

10. 本轮可以实现名称明确的经营替代指标，
    例如“净销售出库成本 / 平均自有库存成本”，
    但必须说明这是经营口径，
    并区分备件消耗、销售退货及成本未知项。

11. 不展示未经确认的利润或毛利。
    如仅有可比较的商业金额与部分成本，
    只能标为相应口径的差额，并说明缺失费用和税费；
    数据不充分时直接不计算。
