## 数据和 API 契约

报价草稿独立 tenant/id/version、客户/项目关系、固定 BOM 版本、整机数量、追加 SKU/数量和明确移除的技术 SKU、价格 scope/tax_included、可选已验证折扣身份。配置关系采用复合租户 FK；计价结果为服务端有类型的快照，记录来源、价格表版本、时间和配置指纹。前端不提交金额。提供列表/详情、创建/编辑、只读试算 POST、折扣码解析 POST。新增/编辑写命令幂等；没有发布、核销、预占或对外发送 API。

客户和项目必须属于本企业且当前用户有客户访问权；报价维护权限 admin/member，只读 viewer；折扣应用另需 quote.discount（首期 admin）。客户权限变化后继续检查，不能通过草稿绕过客户授权。全部入口绑定页面预期企业/context；持会话/membership 锁后进入目录锁和报价锁，协调目录变更及聚合读取。

## 开发规则与未配置边界

- 首期 CNY，沿用价格表含税/不含税口径，不换算税额、税率或汇率。不从 Demo 13% 推导真实政策。
- 根 BOM 主体作为商业基价；包含行不再收费；separate 行和新增部件按所选 scope/税口径取当前已发布价格。用户移除技术包含件不减少根基价，替换件作为新增付费行；没有未经配置的抵扣。
- 发布 BOM 的技术快照保留，报价时重新读取所有实际选中 SKU 当前启停/类别，并对当前配置运行有限规则。开发完整性要求主机、CPU、内存、电源、系统盘，GPU/数据盘/网卡/IB 可选；此规则标为开发门槛而非供应商型号认证。任意 UNKNOWN/BLOCK 均不表示可售/兼容通过；正式销售/发布政策未配置，发布功能未实现。
- 数量正整数；单价 NUMERIC/Decimal 两位；先单价乘行数量再按 HALF_UP 到分、累加行小计，再乘整机数量并到分；金额上界与溢出显式检查。单一百分比折扣用整数基点，按汇总金额计算、HALF_UP 到分，受最小订单额和最大优惠金额约束，最终不得负数。金额 API 为精确字符串。
- 折扣政策必须显式存在于企业配置；本任务只支持单码百分比、不叠加，启停/期间/范围/税口径/权限/最低额/最高优惠验证。无真实政策则拒绝该优惠。测试通过开发脚本植入带“虚构”标签的政策；不提供通用折扣后台，不用 Demo 折扣码当真实政策。
- 不支持次数限制、预占或核销，试算/保存均不消耗额度；不存在“抢到优惠”的承诺。原始折扣码不进入审计或数据库日志，数据库只存按企业散列的匹配值，草稿记录政策 id。后续若加次数限制须另行定义并发预占/释放协议。
- 缺价、停用、未生效/过期价、缺必选件可保存待补全草稿，不能显示有效最终报价。保存与试算区分；重开时同时给出历史已保存结果与当前重新计算差异/需重算状态。配置或价格改变不静默沿用旧总额。
